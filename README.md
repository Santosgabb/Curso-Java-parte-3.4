# Curso de Java: Orientação a Objetos - Parte 3.4 ☕

Módulo de exercícios práticos focados na consolidação dos conceitos de Programação Orientada a Objetos (POO), modelação de entidades do mundo real e implementação de regras de negócio em Java.

---

## 📌 Exercícios e Domínios Implementados

* **Gestão de Lâmpada**: Modelação de estados (ligada/desligada) e controlo de consumo energético.
* **Conta Bancária**: Operações básicas de saldo, limites, depósitos e levantamentos com validações.
* **Controlo de Alunos e Disciplinas**: Cálculo de médias semestrais e verificação de critérios de aprovação.
* **Jogo do Galo (Tic-Tac-Toe)**: Lógica matricial com turnos alternados e validação de vitória.
